# Boutique E-Commerce & Inventory Management System 🛍️

A modern, full-stack luxury retail showcase and administrative inventory control platform built with React, Vite, and Tailwind CSS.

[![Live Demo](https://img.shields.io/badge/Live_Demo-boutique--inventory--chi.vercel.app-purple?style=for-the-badge&logo=vercel)](https://boutique-inventory-gazilo.vercel.app/)

## 🌟 Key Features

* Customer-Facing Storefront: Modern hero interface, responsive product grid, and interactive shopping cart management.
* Admin Inventory Dashboard: Real-time stock tracking, automated low-stock warnings, SKU management, and total valuation metrics.
* Authentication & Authorization: Role-based access control with pre-configured demo credentials for instant testing.
* Modern UX/UI: Fluid grid layouts, micro-interactions, and visual item catalogs.
